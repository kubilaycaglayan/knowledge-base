# Know iOS client

This is a native SwiftUI executable target, not a web wrapper. Open `Package.swift` in Xcode on macOS, select an iOS simulator/device, and configure the `KNOW_API_URL` scheme environment variable to the shared API URL. The package also declares macOS 14 for host-side Swift test/build validation; the client uses Keychain for the JWT and the same `/api/v1` endpoints as the web client and extension.

Implemented daily flows include authentication, dashboard statistics, path creation, item creation with active-path selection, item details, progress updates, item notes, timeline refresh, resource-aware timer start/stop, and dashboard timer targeting by active path and item. The API client and app model accept injected transports, retry transient GET/HEAD failures once without replaying mutations, and report an offline state so response decoding, authentication expiry, and reconnection behavior can be unit tested. Critical SwiftUI controls expose stable accessibility identifiers, and `KnowUITests/KnowUITests.swift` contains the initial authentication UI test source. The Linux development environment cannot compile SwiftUI or execute XCUITest; the repository CI workflow performs the native macOS build. Add the `KnowUITests` XCTest UI target in Xcode, attach this source to it, and run it before App Store distribution.
