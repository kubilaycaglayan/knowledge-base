# Board acceptance criteria

The authoritative acceptance contract for the multi-board feature lives at
[`BOARD_ACCEPTANCE_CRITERIA.md`](../BOARD_ACCEPTANCE_CRITERIA.md).

That file is intentionally kept at the repository root so the implementation
checklist, test traceability, and release status remain easy to find. Update it
with each vertical TDD slice; do not maintain a second, divergent checklist in
this documentation directory.
