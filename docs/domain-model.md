# Domain model

`User` owns paths, notes, and reusable labels. Time entries preserve work duration with explicit `WEB`, `IOS`, `CHROME_EXTENSION`, `MANUAL`, or `IMPORT` sources and can carry zero or more user-owned labels. Notes are standalone knowledge records that may target one path, activity, or time entry, store rich Tiptap JSON plus a searchable plain-text projection, connect to reusable tags through `note_tag`, and use a 30-day soft-delete archive before permanent cleanup. Activities describe what happened, notes preserve knowledge, and a running timer is server-owned with one active timer per user enforced by the service and a PostgreSQL partial unique index. Optional `daily_record` entries preserve a selected calendar date’s note and reusable `daily_label` assignments; portions are retained only for reportable calendar events and are not work duration.
