# Domain model

`User` owns paths, notes, and reusable labels. The `labels` catalog stores one user-owned label per name, while `label_scope` controls whether it is available to notes, calendar records, time entries, or multiple contexts. Time entries preserve work duration with explicit `WEB`, `IOS`, `CHROME_EXTENSION`, `MANUAL`, or `IMPORT` sources and can carry zero or more scoped labels. Notes are standalone knowledge records that may target one path, activity, or time entry, store rich Tiptap JSON plus a searchable plain-text projection, connect to reusable labels through `note_label`, and use a 30-day soft-delete archive before permanent cleanup. Activities describe what happened, notes preserve knowledge, and a running timer is server-owned with one active timer per user enforced by the service and a PostgreSQL partial unique index. Optional `daily_record` entries preserve a selected calendar date’s note and reusable `daily_record_label` assignments; portions are retained only for reportable calendar events and are not work duration. Labels can be managed from the Labels page without duplicating a label for each context.
