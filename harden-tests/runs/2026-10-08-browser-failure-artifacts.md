# Browser failure artifact capture verification

- Date (UTC): 2026-10-08; exact run times not separately recorded.
- Source revision: working tree after `0e34346`, before this evidence commit.
- `frontend/scripts/browser-failure-artifacts.mjs` starts a Playwright trace for each active browser context, saves full-page screenshots and a trace on test failure, and writes metadata containing engine/profile, failure type, and failed-request paths/statuses without query values or request bodies. `scrub-playwright-trace.py` redacts authorization, cookies, passwords, token fields, and email addresses before a trace is kept. Passing tests stop and discard their traces.
- A synthetic capture check used a local page with fake authorization and cookie headers. It generated one PNG, one trace ZIP, and one diagnostics JSON under `harden-tests/local-artifacts/trace-scrub-integration-final/`; an inspection confirmed both fake values were absent from the retained trace.
- The line-history, search, and timer runners save test output and disposable Compose logs under the ignored artifact directory on failure. Metadata records only the commit and browser profile. Passing run metadata remains local; no credentials or account details are committed.
